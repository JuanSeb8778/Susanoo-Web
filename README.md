# ⚡ Susanoo Web

Sitio web temático sobre **Susanoo**, el dios de la tormenta y el mar en la mitología japonesa. Presenta su historia y su familia, su papel en el anime *Naruto Shippuden* y una galería de ilustraciones.

🔗 **Demo en vivo:** https://juanseb8778.github.io/Susanoo-Web/

## 🎓 Contexto

Proyecto académico desarrollado en el **tercer semestre** de Ingeniería de Software en la **Institución Universitaria EAM**.

## 📄 Páginas

| Página | Contenido |
|---|---|
| `index.html` | Inicio: historia de Susanoo, su familia divina y una ficha con sus datos principales |
| `indexNaruto.html` | El Susanoo en *Naruto Shippuden* y los personajes que lo usan |
| `indexPictures.html` | Galería de ilustraciones con visor a pantalla completa |

## ✨ Características

- Diseño inspirado en los grabados **ukiyo-e**: fondo índigo, detalles en bermellón y el nombre del dios en kanji vertical (須佐之男命).
- **Responsive**: se adapta a computador, tablet y celular.
- **Galería con visor**: abre cada imagen en grande y permite pasar entre ellas con flechas o con el teclado.
- **Imágenes optimizadas** en formato WebP para que la página cargue rápido.
- Accesible: navegación con teclado, textos alternativos en las imágenes y respeto por la opción de reducir animaciones.

## 🛠️ Tecnologías

- **HTML5** para la estructura de las páginas.
- **CSS3** con una sola hoja de estilos compartida (`styles.css`): Grid, Flexbox, variables CSS y animaciones.
- **JavaScript** sin librerías para el visor de la galería.
- Tipografías **Shippori Mincho B1** y **Zen Kaku Gothic New** de Google Fonts.

## 🚀 Cómo verlo en local

```bash
git clone https://github.com/JuanSeb8778/Susanoo-Web.git
cd Susanoo-Web
```

Abre `index.html` en tu navegador.
