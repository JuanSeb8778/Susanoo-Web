# ⚡ Susanoo Web

Sitio web temático sobre **Susanoo**, el dios de la tormenta y el mar en la mitología japonesa. Presenta su historia y características, su influencia en el anime *Naruto Shippuden* y una galería de ilustraciones.

🔗 **Demo en vivo:** https://juanseb8778.github.io/Susanoo-Web/

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## 📄 Páginas

| Página | Contenido |
|---|---|
| `index.html` | Inicio: historia y características de Susanoo en la mitología |
| `indexNaruto.html` | Su presencia en *Naruto Shippuden* y sus apariciones en la serie |
| `indexPictures.html` | Galería de ilustraciones |

## 🛠️ Tecnologías

- **HTML5** para la estructura de las páginas.
- **CSS3** con una hoja de estilos por página (`stylesHome.css`, `stylesnaruto.css`, `stylesPics.css`).

## 🚀 Cómo verlo en local

```bash
git clone https://github.com/JuanSeb8778/Susanoo-Web.git
cd Susanoo-Web
```

Abre `index.html` en tu navegador.
